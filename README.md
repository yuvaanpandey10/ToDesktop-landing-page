# Tailwind Practice

A small front-end landing page built with HTML, CSS, and Tailwind via Vite.

## Features

- Responsive landing page design
- Tailwind-based styling
- Interactive FAQ accordion
- Pricing toggle
- Marquee / scroll animation effects
- Modern product landing page layout

## Tech Stack

- Vite
- Tailwind CSS
- JavaScript
- HTML

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
